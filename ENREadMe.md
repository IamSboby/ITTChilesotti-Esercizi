# ITTChilesotti Exercises

Personal repository dedicated to programming exercises completed during my high-school studies.

The goal of this repository is to organize the exercises completed during lessons, so they can be preserved and consulted over time.

To import a `.cs` file into Visual Studio Code, rename it to `program.cs`.

The repository has two main purposes:

- **Reference for other students** — the exercises can be used as a reference when dealing with doubts or comparing different approaches to solving a problem.
- **Personal review** — keeping all the exercises on GitHub allows me to revisit topics I have already studied, review the code, and observe my progress over time.

> The exercises represent work completed during my studies and should not necessarily be considered the only possible solution to a problem.
